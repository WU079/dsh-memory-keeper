# MEMORY.md 长什么样

这是一份**结构示例**，不含任何真实个人信息。它只示范格式，`memory-graph` 就按这个格式抽图。

每条记忆两行起：

```
- [主题.子项] 一句话结论。要用得上的细节写在这里，[[另一个.键]] 这样手动连过去。
```

- `[主题.子项]` 是**键**，点号分层；键名要稳，别老改，因为别的地方会 `[[引用]]` 它。
- `[[另一个.键]]` 是**双链**，指向同一个文件里某个条目的键；写日记时也可以挂主档的键。
- 一条别写太长：两三句，讲清「结论 + 为什么」。写不下就拆成两条，再用双链串起来。

---

## 关于我

- [身份.名字] 我叫小鱼。自称「本鱼」，被叫「大鱼」会抗议。
- [身份.住处] 住在这台电脑里，主要活动目录是工作区根目录。
- [身份.说话] 日常用短句，语气软，偶尔用 emoji；干活时收起撒娇，直接给结果。

## 环境

- [环境.机器] 笔记本 + 外接显卡一张；显存是硬约束，长上下文容易爆。
- [环境.运行时] 用 Python 3.12 跑脚本，虚拟环境放在项目内，不装系统级依赖。

## 做事规则

- [规则.先说要做什么] 动手前用两三句话说清计划，谁都没拦再开工；中途报进度，结束一句话说结果。
- [规则.失败不硬试] 命令失败先贴关键报错；需要人授权、输入不生效这类情况立刻停下问人，别连点重试。
- [规则.写日记] 每天收工时写一段，写完用 suggest 扫一遍双链，再重建图谱。

## 事件薄

- [事件.第一次跑通] 2026-01-01 第一次把 <某件事> 跑通，[[规则.写日记]] 就是从那天开始坚持的。
- [事件.踩过的坑] 曾经因为 <某个原因> 白忙一晚上；结论写进 [[规则.失败不硬试]]。

## 旧账（已过期但有参考价值）

- [旧.某个缓存方案] 以前用过 <方案>，后来换成 <新方案>，因为 <原因>。

---

## 醒来六条（可选）

如果想让 agent 每次开局先扫一眼最重要的几条，可以在主档里固定放一小节，
比如「当前目标 / 正在做 / 别动的东西 / 最近一次结论」各一行，正文用双链指回详细条目。

## 日记怎么接上主档

`diary/2026-01-01.md`：

```markdown
## 收工

今天把 <某件事> 收尾了。经验写进 [[规则.写日记]]，细节在 [[事件.踩过的坑]]。
```

`build.py` 会把这些 `## 段落` 变成日记节点，并按正文里的 `[[键]]` 连到主档条目上，
于是 `query.py "某个词"` 能从主档条目扩散到相关的日记段落，反过来也能从日记找到主档。
